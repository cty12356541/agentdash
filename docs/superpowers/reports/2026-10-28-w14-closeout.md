## dogfood 实录(反重力真机多轨编排真发现)

1. **反重力 `run_command` 非零退出码在 `transcript.jsonl` 而非顶层 `error`**:实测 `exit 7` 命令在反重力宿主中步状态仍为 `DONE`(顶层 `error` 仅承载工具 RPC 异常),真实退出码写于 `transcriptPath` 对应 `step_index` 的 `Command exited with code N.`——由此设计 64KB 尾读 + `Stop` 延迟补读,实装后 `stats --host agy` 直接产出绿侧真码折叠(`passed` 而非 `unknown`);
2. **三字符宿主 `agy` 暴露 `stats` 表头下溢**:`v0.11.0` 实跑 `stats --host agy` 时 `host_w = "agy".len() = 3`,导致 4 列 `"host"` 表头右移错位 1 列——被 `W14-07` 的 `.max(4)` + `display_width` 当场根治;
3. **异步车道屏障先清先跑**:Wave 1 中 `W14-03` 与 `W14-02 + W14-04` 先于 `W14-01` 收工,`ledger.py` 屏障立即解锁 B/C 车道的 `W14-06` 与 `W14-07` 提前并行推进,无需整波死等最慢任务。
